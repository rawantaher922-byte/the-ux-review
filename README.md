# The UX Review – Blog Landing Page

## Overview
The UX Review is a blog landing page focused on user experience (UX), design, and digital trends. It features articles, authors, community content, and a newsletter subscription section.

## Features
- Responsive navigation bar
- Hero section with featured content
- Latest articles with categories and author information
- Trending articles section
- Categories sidebar
- Meet the Authors section
- Community section with testimonials
- Newsletter subscription form

## Technologies Used
- HTML5
- CSS3
- Google Fonts (Exo)

## Getting Started
1. Clone or download the repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser.
4. Make sure the CSS and images folders remain in their original locations.

## Project Goal
This project demonstrates front-end development skills through a structured blog landing page with multiple sections and a clean user interface.

Created as a front-end practice project.
