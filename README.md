# DJI Mavic 4 Pro – Product Landing Page

A modern product landing page designed to showcase the DJI Mavic 4 Pro drone. The page presents product details, technical specifications, customer reviews, and related accessories in a clean, user-friendly layout.

## Project Overview

This project is an e-commerce-style product landing page that highlights the DJI Mavic 4 Pro and helps visitors explore its features, compare it with other drones, read customer reviews, and discover compatible accessories.

## Features

- **Navigation Bar:** Links to the main sections of the page.
- **Hero Section:** Product introduction with an image, discount, pricing, and purchase buttons.
- **Product Comparison:** A comparison table featuring technical specifications and competing products.
- **Customer Reviews:** Overall rating, review distribution, and customer testimonials.
- **Related Products:** Recommended accessories with prices and add-to-cart buttons.
- **Footer:** Additional navigation links and social media icons.

## Technologies Used

- HTML5 – Page structure and content.
- CSS3 – Styling and layout.
- Google Fonts (Roboto) – Typography.
- Image assets – Product images, avatars, and icons.

## Getting Started

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

Make sure the `css` and `images` folders remain in their expected locations so the page can load its styles and images correctly.

The goal of this project is to practice front-end development by building a structured and visually appealing product landing page using HTML and CSS.
